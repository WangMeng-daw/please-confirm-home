# 请确认回家

深夜三部曲第三部。通过一部模拟手机寻找失踪的女儿，翻阅聊天、旧照片、帖子与网页，走向三种结局。

**在线入口：https://wangmeng-daw.github.io/please-confirm-home/**

## 封面与资源预加载

封面选择“下载游戏资源”可校验并保存全部资源。支持进度显示、暂停、继续下载及中断重试；完成后从本机缓存加载。也可选择“开始寻找”直接在线游玩。首次完整下载约410 MB，建议使用Wi-Fi。图片与玩法均发生在模拟手机里，不操作真实微信、小红书或相册。

存档保存在当前浏览器。设置中的备份与恢复可导出存档；不同域名和设备之间请手动转移。离线状态可浏览已缓存内容，NPC自由聊天需要联网服务。

## NPC服务状态

GitHub Pages负责静态游戏，不能运行Node服务。本次已发布全部角色的聊天客户端和服务端源码，线上聊天服务尚未创建。入口会明确提示该状态，接口失败不会用固定人物台词冒充模型回复。关键剧情与结局由固定脚本处理。

连接步骤见 [DEPLOY-NPC.md](DEPLOY-NPC.md)。`npc-service-config.js`只保存公开服务地址，禁止填写模型密钥。

## 本地运行

Node.js 22；在仓库外保存private.env或通过环境变量配置NPC_API_KEY、NPC_BASE_URL、NPC_MODEL，然后运行`node server/server.mjs`，打开http://127.0.0.1:8765/。
